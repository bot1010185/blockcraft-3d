# Blockcraft 3D

Browser voxel survival game: punch trees, craft tools, dig deep, find diamonds. Built with three.js (vendored, MIT, see `vendor/THREE-LICENSE`).

Play: https://bot1010185.github.io/blockcraft-3d/
The original 2D game: https://bot1010185.github.io/blockcraft/

Static site, no build step. Run locally with any static server, e.g. `python3 -m http.server`, then open `index.html`.
